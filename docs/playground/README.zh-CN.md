# New API 操练场完整功能说明

本文说明操练场的功能与数据边界；部署配置和验证报告由各安装环境自行保存。

## 入口与发送消息

登录本站后进入操练场，选择当前账号可用的分组与模型，再输入消息。无可用模型、模型分组仍在加载或当前回复尚未结束时不能发送新请求，切换分组不会使用旧列表中的模型误发。

消息走本站原有中转、额度、限流和计费链路，已执行的搜索工具调用也按站点现有工具计价结算；仅勾选搜索而没有实际调用，不会虚记一次搜索调用。重新生成和“编辑后发送”都是新模型请求，可能产生新的用量。现有 OAuth、应用收款及 SDK 功能保持；操练场不向普通用户开放渠道管理，也不提升原有模型或分组权限。

## 文件、图片、截图和拍照

附件菜单提供上传文件、上传图片、截取屏幕和拍照；也支持拖放文件、粘贴剪贴板文件。在待发区检查附件并可逐个移除，确认发送前不会调用模型。可以仅带附件发送，不强制填写额外文字。附件正在读取时不能再次提交；读取或发送准备失败时保留原草稿和已选附件。

| 项目 | 当前限制 |
| --- | --- |
| 文件数量 | 每条消息最多 6 个 |
| 单个文件 | 最多 8 MiB |
| 全部附件 | 每条消息合计最多 12 MiB |
| 文本文件 | 每个最多 1 MiB，必须为有效 UTF-8 |
| 图片 | PNG、JPEG、WebP、GIF |
| 文档 | PDF，以及常见文本、Markdown、JSON、CSV、日志、YAML、XML、HTML、代码文件 |

附件准备在浏览器内完成。文本被解码并作为消息文本传递，图片和 PDF 以内容数据随消息发送，不创建公开文件下载地址。空文件、伪装格式、无效 UTF-8、数量或大小超限会明确提示。附件名在消息中展示，图片可预览、文本可展开，PDF显示类型与文件名；此处不承诺浏览器内完整PDF阅读器。

拍照会先打开可见预览，用户点击拍摄后加入图片；拍摄或关闭窗口即停止摄像头。截图由用户在浏览器选择屏幕或窗口，只捕获一张图片，不录音；完成、取消、失败或离开页面会释放捕获资源。摄像头、屏幕捕获都取决于 HTTPS/可信本地环境、浏览器支持和用户主动授权。手机或浏览器不支持时，改为选择图片或上传系统截图即可。

图片理解、PDF读取仍要求所选模型和渠道支持，上传成功不等于模型支持。模型上下文、图片数量、格式和文档页数等还受上游限制，不保证所有模型都能使用所有附件。

## 联网搜索

点击地球图标切换联网搜索，再发送消息。启用后请求中包含模型原生搜索选项，可在参数面板选择低、中、高搜索上下文。关闭后不发送搜索选项。

该功能请求所选模型及渠道的原生搜索能力，不是本站独立爬虫。当前适配 OpenAI 兼容渠道的 Responses 搜索工具及原生搜索模型 Chat 选项、Claude 原生搜索工具、Gemini googleSearch；其他尚未确认的渠道明确返回不支持。工具启用后仍由模型决定是否检索，不保证每次都会搜索。模型不支持时需要关闭选项或改用支持的模型。搜索上下文设置按对应协议转换，Gemini没有完全等价的上下文大小参数，不据此承诺相同结果。只有上游真实返回的引用/来源才会显示链接，不用模型正文中的“我已搜索”代替搜索证据，也不伪造来源列表。

## 参数设置

基础数值参数分别有启用开关；只有启用的参数才随请求发送。显式 0 会按参数语义保留，不被当作未填写。

| 参数 | 界面范围或行为 |
| --- | --- |
| 温度 | 0–2，步长 0.1 |
| Top P | 0–1，步长 0.1 |
| 频率惩罚 / 存在惩罚 | -2–2，步长 0.1 |
| 最大输出令牌 | 1–200000，实际可用上限由模型决定 |
| 随机种子 | 0–2147483647，可留空；不保证模型输出绝对可重复 |
| 系统指令 | 最多16000字符，设定角色、语气和规则 |
| 流式回复 | 开启时边生成边展示；关闭时等待完整返回 |
| 推理强度 | 模型默认 / 低 / 中 / 高 |
| 回复格式 | 文本 / JSON对象；JSON模式同时发送格式要求与相应指令 |
| 停止序列 | 每行一个，最多4个，每个128字符；空行不发送 |
| 搜索上下文 | 搜索开启时可选低 / 中 / 高 |

“重置参数”恢复数值与启用状态的默认值，并清空系统指令、停止序列，恢复流式，关闭搜索及其他可选格式设置；模型和分组选择保持。

这些参数是模型可选能力，不能保证所有模型接受。使用不支持的参数导致上游拒绝时，应关闭对应参数或改用支持的模型。JSON格式不是业务数据验证器，仍需由使用方解析并校验返回内容。

## 回复展示、操作和真实统计

消息支持 Markdown 渲染、源码预览、复制、编辑、重新生成、删除；手机通过消息菜单操作。生成过程中禁止会改写对话的编辑、删除和重生成，仍可停止当前生成。

Markdown回复不再因为整条消息超过20000字符而变成纯文本；较长回复仅关闭逐词渐入动画。代码围栏和行内代码按原内容展示，语言标记为 `md` 或 `markdown` 的示例也保留其代码用途；代码中的 `<think>`、`</think>` 和消息包装标签不会被误拆或清除。源码预览和复制使用消息原文。真实推理内容中的未闭合行内反引号不会再吞掉推理结束后的回答。

数学公式支持明确的行内分隔符 `$...$`、`\(...\)` 和块级分隔符 `$$...$$`、`\[...\]`，由KaTeX排版；代码中的公式仍作为代码展示。普通括号不被猜测为公式，`$5 and $10`、`$5–$10` 等常见美元价格文本保留符号。公式未写完、语法无效或单个公式超过20000字符时完整显示其源码，不影响其余正文；此限制独立于整条回复的Markdown渲染。宽公式可在自身区域横向滚动。KaTeX的宏展开和尺寸受到限制，不保证支持全部LaTeX宏包。

某条回复的预处理、解析或渲染发生异常时，该回复显示保留换行的原始文本；收到新正文或生成状态变为完成后会重新尝试渲染，避免单条异常阻断整页。修复不会在缺少原始文本时重建先前已错误改写的历史内容。

“保存编辑”只改浏览器当前消息；用户消息“编辑后发送”会从该位置重新请求。编辑或重发会保留该消息已有附件，编辑器会提示这一点。重新生成也从选定位置重建后续回复，当前位置之后的旧消息会被移除；当前不是多分支对话或版本回溯界面。需要保留旧内容时先导出。单条删除移除该消息，清空整个对话需要确认。

界面展示上游实际公开返回的推理内容，可折叠查看，不生成模型未提供的内部思维。首字时间是浏览器收到第一个可显示文本或推理片段的时间，包含网络和浏览器处理；总响应时间是本次响应耗时，两者不是同一指标。

输入、输出、总令牌、缓存命中、缓存写入与推理令牌取上游最终 usage。缺失字段隐藏，不估算为0；上游明确返回0时会显示0。流式统计也可能直到末尾才出现，不保证每个渠道都提供全部字段。

输出长度受限、内容过滤或只返回工具调用而没有文本会显示实际状态。停止生成会取消当前请求并保留已收到内容，不保证上游已经发生的消耗全部退回。网络中断不会把未完成回复伪装成完整成功；页面刷新后已收到的部分内容保留。

## 浏览器历史与导入导出

每个账号在当前浏览器保存一份当前对话，配置同样按账号隔离；没有多会话列表，也不做服务器跨设备同步。退出或切换账号会清理内存中的旧账号数据，新的读写仍校验当前账号。不会自动把无所属账号的旧版全局历史归给任意用户。

对话保存到 IndexedDB，设置保存到账号范围内的浏览器存储。界面明确显示保存中、已保存或保存失败，长回复生成期间也会定期保存已收到的片段。当前上限为2000条消息、20 MiB序列化对话数据；不能把附件输入12 MiB上限直接等同于可保存大小，图片/PDF编码和整个历史都会占用额度。失败时保留页面内当前内容并提示重试或导出，不静默删除长消息、重复章节或旧历史。

为减少一次渲染负担，初始显示最近24条；点击“加载更早的消息”每次展开更早24条。此为显示分批，不删除较早消息，也不限制发送上下文只含这24条。

工具栏提供：

- **导出JSON**：保存带附件、统计和有效设置的规范对话文件，可用于恢复；设置暂时无效时省略无效设置，仍可备份消息。
- **导出Markdown**：生成便于阅读的文本，包含消息、可用附件和推理内容；恢复请使用JSON。
- **导入对话**：只接受规定格式的JSON，先校验文件大小、消息、附件数据与来源地址，再确认替换当前消息。参数保持当前设置，不自动向模型发送。JSON导入允许额外128 KiB的格式/设置元数据，实际消息数据仍不得超过20 MiB；流式回复增长导致对话超过20 MiB时，页面内完整内容仍可导出备份，但超限备份不能直接重新导入，系统不会为导入而静默截断。2000条消息是提交前校验的数量上限；超出时不会继续追加。
- **导入旧版历史**：仅在发现旧数据时出现；旧数据没有账号所有者，必须由用户确认属于自己后导入。
- **清空对话**：确认后清除当前账号在此浏览器的当前消息；需要保留时先导出。

刷新、无痕模式、浏览器存储配额和清理站点数据都会影响本地保存。该隔离防止应用正常账号切换混用历史，不是对本机拥有访问权限的人提供加密隔离。导出文件含对话和附件内容，请按实际敏感程度保存与分享。
