# Codex 前端设计与 ZCode 源码复用说明

日期：2026-10-06。本轮按用户要求重做 Codex 网页界面，直接复用并适配 ZCode 的展示层源码，包含 Markdown 渲染。后端沿用已经上线的“每个用户一个 Docker 个人环境”实现。本文说明代码来源、页面组织和服务边界；本轮正式上线状态与最终验收以 [完整中文文档](README.zh-CN.md) 的发布记录为准。

## 改造范围

上一版虽然具备项目和任务操作，导航、标题、环境条与结果面板的视觉层级仍不清楚，手机会话空间不足，回复与工具输出的阅读体验也不统一。此次直接采用上游工作台的页面布局、主题变量、消息排版和结果面板组件，围绕“开始任务、跟进执行、审阅结果、继续原项目”重新组织界面。

此次重做限定在 `/codex`。New API 的品牌、账号、权限、语言与主题选择继续保留，其他功能页不改成 ZCode。一个项目仍对应独立文件与会话；同一管理员的项目共用个人 Docker 环境，用户不需要自行配置容器或宿主路径。

## Markdown 渲染

渲染链使用上游的 Streamdown 组件和 CJK、代码、数学公式、Mermaid 插件；消息增量生成时按流式模式处理未闭合 Markdown，完成后转为静态渲染。保留上游对单美元公式的判断，避免把 `$HOME`、金额与价格区间误认成数学表达式；中文删除线、列表、引用、表格与标题采用同一套展示组件。

代码块提供语言标记、复制和自动换行，生成完成后执行语法着色，长代码在块内滚动。表格支持复制为 Markdown 与下载 CSV，宽表格在自己的区域横向滚动。符合预算的 Mermaid 内容在浏览器中绘图，结果 SVG 经过清理；过大、非法或暂不能渲染的图保留源代码，渲染失败不会把整段会话清空。字体、长文本、代码换行、列表缩进以及明暗主题须以实际浏览器结果确认。

本站适配只允许普通 HTTP / HTTPS 外链，点击后在新页面打开；原始 HTML 不执行。远程图片由浏览器按消息指定地址加载，使用无来源引用信息策略；桌面本地路径、文件预览协议、上游截图或媒体服务没有接入。界面中的 Markdown 仅负责展示，项目文件操作仍经过本站已授权的文件 API。

## 页面与任务流程

首页显示简洁问候与任务输入，已有项目可以从侧栏查找和继续。侧栏集中呈现最近项目、正在执行的项目、搜索和归档；项目名称与状态保持可辨认，不重复堆叠站点导航和页面标题。个人环境通过紧凑入口查看当前状态、占用项目、资源上限与休眠操作。

会话优先呈现用户任务、助手回复和可读的执行进度，工具过程按需展开。需要审批或回答的问题直接展示操作理由、命令、目录或权限路径，原始请求 JSON 收入详情。用户向上阅读时保留位置，通过最新消息入口返回；重新连接按后台快照与事件游标恢复，不重复提交任务。

输入区保持 Code / Ask、模型与推理强度可用，发送和停止有明确状态。中文输入法组合中不触发发送；Enter 发送，Shift + Enter 换行。草稿和待重试请求编号继续按账号、项目保存到当前标签页的 `sessionStorage`，不包含模型密钥。提交失败保留草稿，执行期间可以准备下一条消息。

结果面板围绕文件、变更和命令日志组织。文件默认查看，主动进入编辑后才保存；CodeMirror 的行号、语法高亮、撤销与保存快捷键保持可用，冲突时保留本地编辑。差异来自实际项目文件和基线，补丁下载与项目导出继续走现有接口。命令日志是任务执行记录，不是独立交互终端。

桌面会话与结果区域可调整宽度并独立滚动；手机以会话为主，侧栏与结果面板按需打开。长文件路径、代码、表格和多语言文字不得撑破页面；按钮需要可访问名称与键盘焦点，主题、窄屏与实际任务内容共同验收。

## 服务边界与许可

任务仍由真实 Codex App Server `0.160.0` 在每用户一个 Docker 的环境中执行，访问仍限定站内管理员。此次没有接入 ZCode 的账户登录、Coding Plan、支付、反馈、遥测、模型网关、桌面运行时、插件市场或团队服务，没有修改本站模型渠道和计费规则。UI 源码复用不等于运行 ZCode 完整产品，也不承诺与其所有发行形态功能一致。

## 验证方式

构建前检查 TypeScript、目标文件 lint、实际使用的七语言文案与插值参数。行为验证覆盖任务草稿与发送停止、文件编辑和冲突、真实补丁行号，以及 Markdown 增量、代码、表格、公式和 Mermaid 的关键分支。浏览器使用本轮最终产物确认桌面与手机、明暗主题、任务执行和渲染，不将旧版组件测试或截图作为本轮 UI 已通过的证据。

每用户 Docker 与持久化数据的已部署证据位于上一环境版本目录；本轮不重复迁移生产项目。本轮构建、最终截图、公开资源哈希与部署结果在发布后统一写入完整中文文档。
